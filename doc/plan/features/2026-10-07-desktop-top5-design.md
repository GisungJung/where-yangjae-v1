# 데스크톱 우측 영역 TOP5 대시보드 전환 — 설계

- 작성일: 2026-10-07
- 범위: 데스크톱(≥1024px) `HomeWorkspaceLayout` 우측 영역. 모바일은 변경 없음.

## 1. 화면

| 라우트 | 우측 영역 |
|---|---|
| `/` | 별점 TOP5 대시보드 — 🍚 점심 / 🍻 저녁회식 2행(위아래), 각 행은 1~5위 카드 가로 5칸 |
| `/restaurants/:id` | 카카오맵 (선택 식당 핀 1개 + 센터링) — 기존과 동일 |

- 우측 영역을 꽉 채움: 두 행이 남는 높이를 반씩, 카드는 행 높이만큼 늘어남 (행 최소 260px, 넘치면 스크롤).
- 카드: 대표 사진 썸네일(없으면 🍽️ 플레이스홀더) + 순위 배지(1~3위 강조) · 식당명 · 카테고리 칩 · ★평균 · 평가 수.
- 카드 클릭 → `/restaurants/:id` (상세 패널 + 지도 전환).
- 로딩: 스켈레톤 카드 5개. 5위 미만이면 빈 점선 카드로 자리 유지 (격자 고정).
- 에러는 리스트 패널의 ErrorBox가 담당 (TOP5는 빈 상태로 표시).

## 2. 순위 규칙 (`src/utils/ranking.ts` `selectTopRanked`)

- 대상: `status === '운영중'` ∧ `sheet_type` 일치 ∧ `rating_count >= 2` ∧ `avg_score !== null`.
- 정렬: 평균 ↓ → 평가 수 ↓ → 이름 ↑ (ko locale).
- 최대 5건. 리스트 패널의 검색·필터와 무관한 전체 기준.
- 데이터: 레이아웃이 이미 로드하는 `useRestaurants()` 결과 재사용 — 추가 쿼리·DB 변경 없음.

## 3. 트레이드오프

- 지도는 식당 선택 시에만 마운트 → 첫 화면에서 카카오 SDK 로드가 지연된다(초기 로딩 이득).
- 상세 열기/닫기마다 지도 재마운트 — SDK 스크립트는 캐시되므로 지도 인스턴스 생성 비용만 발생.
  거슬리면 CSS 숨김으로 상시 마운트 유지 방식으로 전환 가능.
- 기존 `/`의 "필터 결과 전체 핀" 지도 뷰는 제거됨.
